## 2. Running the AI Model on Google Colab

To run the model backend using Colab's free T4 GPU, follow these steps:

### File to Upload:
* Use the **`AetherMind_Llama3.ipynb`** (or **`AetherMind_Llama3_V2.ipynb`**) notebook located in the project root folder.

### Steps to Run:
1. **Open Google Colab:** Go to [colab.research.google.com](https://colab.research.google.com/) and sign in.
2. **Upload Notebook:** Click on **File -> Upload notebook** and select `AetherMind_Llama3.ipynb`.
3. **Change Runtime to GPU:**
   * Go to the top menu and select **Runtime -> Change runtime type**.
   * Under **Hardware accelerator**, select **T4 GPU**.
   * Click **Save**.
4. **Run All Cells:** Go to **Runtime -> Run all** (or press `Ctrl + F9`).
5. **Wait for Gradio Link:**
   * The script will install dependencies, load the model (`unsloth/llama-3-8b-Instruct-bnb-4bit`), attach the LoRA adapters, train on the dataset, and launch a Gradio interface.
   * After approximately 5 minutes, scroll to the bottom cell. Look for the public sharing link generated by Gradio (it will look like `https://xxxxxxxxxxxxxx.gradio.live`).
6. **Connect the UI:**
   * Copy the public Gradio URL.
   * Open the AetherMind UI locally (`python run_ui.py` or double-click `claude_ui/index.html`).
   * Click the **Settings (gear icon)** in the UI and paste the Gradio link into the **API Endpoint** input field.
