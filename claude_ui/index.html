Recursion is a method where the solution to a problem depends on solutions to smaller instances of the same problem. For the Fibonacci sequence, each number is the sum of the two preceding ones.

fibonacci.py 
def fibonacci(n):
    # Base cases
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    
    # Recursive helper
    def fib_recursive(k):
        if k <= 1:
            return k
        return fib_recursive(k-1) + fib_recursive(k-2)

    return [fib_recursive(i) for i in range(n)]

# Example usage:
n_terms = 10
print(f"First {n_terms} terms: {fibonacci(n_terms)}")

In this implementation, fib_recursive(k) calculates the k-th term. Note that for large values of $n$, this recursive approach can be inefficient due to redundant calculations. For production code, an iterative approach or memoization is recommended.
