# AetherMind - AI Startup Mentor

A Claude-inspired AI frontend connected to a fine-tuned Llama-3 8B model for Indian startup mentoring.

## Setup

1. Run `AetherMind_Llama3.ipynb` on Google Colab (with T4 GPU)
2. Copy the Gradio public URL
3. Open the frontend and paste the URL in Settings

## Local Development

```bash
python run_ui.py
```

Open http://localhost:3000

## Deploy to Vercel

Push to GitHub, then import in Vercel dashboard.
